# Smart India Hackathon — SIH 26122

## Hackathon Participation

This project was developed as part of the **Smart India Hackathon (SIH)** for the following problem statement:

- **Problem Statement:** 26122
- **Title:** Infrastructure Progress Tracking
- **Event:** Smart India Hackathon

## Team Contribution

This was a collaborative team project. I contributed to the project by **supporting the team during development and helping with various implementation and integration tasks**.

## Key Technical Components

- **Frontend:** React
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **AI/ML:** LLM API, Pandas, Speech-to-Text API
- **Authentication:** JWT

## Project Overview

The solution focuses on **infrastructure progress tracking**, providing a technology-driven approach to monitor and manage progress in infrastructure projects.

The application combines a React frontend, FastAPI backend, PostgreSQL database, and AI/ML capabilities to support progress tracking and interaction with project data.
